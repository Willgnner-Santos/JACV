# JACV Project

## Overview
This repository contains the complete source code for the **JACV** project. It is focused on Legal Natural Language Processing (Legal NLP), aiming to process, analyze, and construct datasets from legal documents.

The pipeline comprises several stages, including:
- Structural and Content Exploratory Data Analysis (EDA)
- Data Preprocessing and Anonymization (CNJ standards)
- Dataset Construction
- Model Fine-Tuning and Evaluation
- Results Analysis

## Repository Structure
- `Notebooks/`: Contains the Jupyter Notebooks with the complete pipeline from data exploration to model evaluation.
- `Results/`: Directory designated for storing the output results and analyses.

## Dataset Availability
In compliance with legal and ethical requirements, the textual corpus will not be fully available in an open format, but may be provided upon request for academic purposes, subject to institutional authorization and the signing of a confidentiality and responsibility agreement, in accordance with the Brazilian General Data Protection Law (LGPD).
